# TuxunDL Windows 1.3.2 — 节点组一键选最快

## 新功能

- **每个节点组多了「选最快」按钮**：在节点页的分组标题右边点一下，这个组会立刻整体测速一遍，然后自动帮你切到延迟最低的那个节点，不用再一个个点着试：
  - 测速结果会直接标回每个节点后面，哪个快哪个慢一目了然
  - 测不通的节点自动跳过，不会选到死节点
  - 测速期间按钮显示「测速中…」，测完自动完成切换
- 和原来的「全部测速」不冲突：全部测速是把所有组都测一遍看个总览，「选最快」是测完顺手就帮你选好

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.3.2.msi`
- EXE 安装包：`TuxunDL-1.3.2.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 到节点页，在任意一个分组点「选最快」，等它测完，看是不是自动切到了延迟数字最小的节点
- 再点一次「全部测速」对照一下，「选最快」切过去的节点和全组最低延迟对不对得上
