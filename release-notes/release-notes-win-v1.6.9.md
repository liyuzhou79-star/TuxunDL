# TuxunDL Windows 1.6.9 — Ctrl+F 直达搜索框，设置能一键恢复默认

这一版是两个顺手的小改进：带搜索框的页面现在按 Ctrl+F 就能直接跳进搜索框打字，不用先伸手点一下；设置页多了一个「恢复默认设置」，设置调乱了一键回到出厂状态，订阅和收藏都不会被动。

## 新功能

- **Ctrl+F 聚焦搜索**：在节点、连接、规则、日志这四个带搜索框的页面里，按 Ctrl+F 光标就落进该页的搜索框，可以直接输入筛选。在主页、订阅、设置这些没有搜索框的页面按 Ctrl+F 不会有任何反应，也不会干扰正在输入的其他内容
- **恢复默认设置**：设置页「关于」上方新增一节。点「恢复默认设置」后按钮会先变红、显示「再点一次确认恢复」，再点一次才真正执行（点「取消」可反悔）。恢复的是连接模式、混合端口、各项开关和主题色；订阅列表、收藏的节点、置顶的订阅都不动。模式和端口类设置在下次连接时生效，主题色立刻变回默认的靛蓝

## 说明

- 这次更新的是 Windows 版；按三平台同页的规矩，本页照样附上 Android 现行正式版（1.4.0）和 Linux 现行正式版（1.0.0）的安装包
- 这两处改动都在桌面端共享代码里，Linux 版下一次发版时也会带上

## 真机建议验一下

- Ctrl+F：分别打开节点、连接、规则、日志四个页面，每个页面按一次 Ctrl+F——光标应立刻出现在该页搜索框里，能直接打字筛选；再打开主页和设置页按 Ctrl+F，应没有任何反应
- 恢复默认：先随手改几处设置（换个主题色、把混合端口改成别的数字、打开一两个开关），再到设置页点「恢复默认设置」——第一下按钮变红并提示再点一次，此时点「取消」应能退出且设置不变；重新点并确认第二下后，主题色应立刻变回靛蓝，这一页的开关和端口都应回到默认；订阅页的订阅、节点页的收藏应原样还在
