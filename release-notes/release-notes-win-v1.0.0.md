# TuxunDL Windows 1.0.0 — 电脑版来了

TuxunDL 的 Windows 版第一版。和安卓版在同一个仓库、同一个产品下，版本号独立从 1.0.0 开始，发布标签带 `win-` 前缀，两边互不干扰。

## 这一版有什么

- **两种连接模式**：系统代理（免管理员）和 TUN（接管全部流量，需以管理员身份运行），在设置里切换
- **订阅管理**：添加、更新、切换订阅，配置保存在本机
- **节点页**：按分组看节点，点一下切换，每个节点可单独测延迟
- **首页实时状态**：大圆按钮启停，连接后实时显示当前节点和上下行速度
- **规则与日志页**：能看当前生效的规则列表，也能翻应用和核心的日志
- **系统匣**：关窗口不退出，缩到系统匣继续跑，从匣里退出会自动恢复系统代理
- **检查更新**：只认 `win-v` 开头的 Windows 发布，不会和安卓版串扰

## 说明

- 内核是开源的 mihomo，和安卓版同源；安装包已经把内核打进去了，装完就能用，不用自己找核心
- 桌面端的界面和代码全部是本项目原创，没有套用其他 Windows 客户端
- 本项目完全开源（GPLv3），Windows 版代码在仓库的 `desktop/` 目录

## 下载

- MSI 安装包：`TuxunDL-1.0.0.msi`
- EXE 安装包：`TuxunDL-1.0.0.exe`
- 两个任选其一，Windows 10 / 11，64 位
- 本页同时附上 Android 现行正式版安装包（1.2.1）：`tuxundl-1.2.1-arm64.apk`（新机型）与 `tuxundl-1.2.1-legacy-armeabi-v7a.apk`（老机型）。Android 1.2.2 已开发完成，因正式版坚持本地签名（签名钥匙不托管在网上），将稍后补发。

## 真机建议验一下

- 装好后添加一个订阅，到首页点连接（先用系统代理模式），确认能正常上网
- 到节点页切换节点、测一次延迟
- 关掉窗口，确认程序缩到系统匣；从系统匣退出后，确认系统代理已恢复原样
- TUN 模式：以管理员身份运行程序，在设置里切到 TUN 再连接，确认能正常上网
