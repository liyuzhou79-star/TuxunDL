# TuxunDL Windows 1.6.2 — 日志更好读，订阅失败有原因

## 新功能

- **日志按级别着色**：日志页的每一行按级别上色——错误是红色、警告是橙黄色、普通信息保持灰色。一大片日志里，出问题的地方一眼就能看出来，不用逐行读
- **搜索关键词高亮**：在日志页搜索时，命中的关键词会直接在行里高亮标出来（不只是把不相关的行过滤掉），上下文还在，找东西更快
- **订阅更新失败，原因写在卡片上**：以前单个订阅点「更新」失败，只在页面上方闪一行提示，很容易错过。现在失败原因直接红字显示在那个订阅自己的卡片上，一句话说清：服务器返回了错误（带状态码）、网络连接失败、网络超时、或者返回的内容根本不像订阅配置（多半是链接失效了）。「更新全部」时某个失败了，也会把原因留在它自己的卡片上；下次更新成功后提示自动消失

## 说明

- 这次只更新了 Windows 版，改的是日志页和订阅页，其他功能和 1.6.1 完全一样
- 按三平台同页的规矩，本页照样附上 Android 现行正式版（1.3.0）和 Linux 现行正式版（1.0.0）的安装包

## 下载

- MSI 安装包：`TuxunDL-1.6.2.msi`
- EXE 安装包：`TuxunDL-1.6.2.exe`

## 真机建议验一下

- 连接后到日志页翻一翻：有错误/警告的行应该是红/橙黄色；在搜索框打一个常见词（比如某个节点名），命中的地方应高亮
- 断开网络，到订阅页对任意订阅点「更新」：它的卡片上应出现红字失败原因；恢复网络再更新成功，红字消失
