# TuxunDL Windows 1.5.2 — 日志导出与自动滚到底

## 新功能

- **日志页加「导出」按钮**：点一下弹出系统保存对话框，把当前来源（应用日志或核心日志）的完整内容存成一个 `.log` 文件，存哪儿、叫什么都自己定。出问题要发日志给人看时，不用再去翻程序的数据目录了
- **日志页加「自动滚到底」开关**（默认开）：打开日志页就直接停在最新一行；开着自动刷新时，新日志一出来也自动跟到底，不用手动往下拖。想安静往上翻旧日志时，把它关掉就行

## 说明

- 导出的日志是当前来源的完整文件内容，不受页面上搜索框过滤的影响；页面搜索只是方便在屏幕上看
- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.5.2.msi`
- EXE 安装包：`TuxunDL-1.5.2.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 打开日志页，看是不是直接停在最底下最新一行；再开「自动刷新」，看新日志出来时画面有没有自动跟到底
- 点「导出」，存一个文件下来，用记事本打开看内容全不全
