# TuxunDL 1.0.2

1.0.1 後的小修補。

## 這個版本有什麼

### 日誌搜尋與篩選（新）
- 日誌頁頂部加搜尋框，輸關鍵字即時篩選日誌行，不分大小寫
- 下方一排等級 chips：全部／錯誤／警告／資訊，等級選擇重開 App 後仍記得
- 篩選在後台做，打字不卡；即時串流與歷史日誌檔案都生效

### 訂閱到期提醒（新）
- 訂閱卡上：到期前 3 天內顯示「訂閱將於 X 天後到期」，已過期顯示「訂閱已到期」
- 沒有到期日的訂閱不顯示

## 下載與安裝
- 標準版（arm64 新機型）：下載 `tuxundl-1.0.2-arm64-v8a.apk`
- 老機型版（32 位舊機型）：下載 `tuxundl-1.0.2-legacy-armeabi-v7a.apk`
- 標準版從 1.0.1 升級：同一把固定鑰匙簽名，直接覆蓋安裝
- 源代碼：點下面的 Source code (zip) 下載，或看 tag `v1.0.2`
