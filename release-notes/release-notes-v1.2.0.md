# TuxunDL 1.2.0 — 吉祥物大版本

## 這版有什麼

**吉祥物小機器人**
- 首頁右上角進駐一隻天線連著節點的小機器人，顏色跟著主題走
- 連點它三下有彩蛋：累計搬運流量、累計連接時長、使用天數，還有「摸摸頭」互動
- 附帶修好：首頁節點磚的直連延遲不再顯示嚇人的「65535 ms」，改顯示「超時」

**大圓啟停按鈕四態動畫**
- 未連接：空心環慢慢呼吸
- 連接中：旋轉弧＋「正在連接 → 正在握手」階段文字，連不上會小晃一下提醒
- 已連接：光環保留，流量衝高時會「心跳」一下，速度數字滾動切換
- 停止中：灰色旋轉弧

**首頁長按拖拽排版**
- 長按任意磚塊或監控卡進編輯模式（卡片會輕輕晃），按住就能拖到想要的位置，排法會存下來
- 大圓按鈕和模式列固定不動

**流量統計重做**
- 普通圖表改看最近 2 分鐘：平滑曲線＋漸層填充＋峰值標示
- 點統計卡進「進階模式」：近 24 小時每小時流量柱圖、今日連接時長、連接品質評級（平均延遲 / 抖動 / 失敗率 / 卡頓次數，只統計已連接期間）
- 「收藏本次連接」：把這次連接的節點、時長、流量和品質評級存成紀錄卡，之後可翻看、可刪除
- 注意：24 小時圖和彩蛋的累計數據都從這版開始累計，剛升級時是空的，屬正常

**節點測速體驗**
- 全部測速時，每個等結果的節點都顯示「測速中…」
- 超時的節點紅字顯示「超時」，不再留空白或怪數字
- 點某個節點的延遲數字，可以只重測那一個（底層仍走群組測速，同群其他節點的延遲會順帶刷新）

**GitHub 倉庫大翻新**
- README 重寫：徽章、截圖、功能總覽、下載對照表
- 新增 CHANGELOG、CONTRIBUTING、SECURITY 與 issue / PR 模板

## 下載

- 標準版（新機型）：`tuxundl-1.2.0-arm64.apk`，直接覆蓋 1.1.0 安裝
- 老機型版：`tuxundl-1.2.0-legacy-armeabi-v7a.apk`，直接覆蓋舊版安裝

## 真機建議驗一下

- 拖拽排版的手感（長按會不會誤觸跳頁、拖到一半滑不滑）
- 連接中動畫：國內網路握手較慢時，「連接失敗」的小晃會不會太早觸發（目前 4 秒）
- 品質評級：直連模式延遲恆為特殊值，評級會偏低，屬預期
- 大群組全部測速時「測速中…」是否順暢
