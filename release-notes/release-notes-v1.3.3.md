# TuxunDL 1.3.3 — 小修小补：订阅能置顶了＋节点分组一键全展开/全折叠

这一版继续小修小补，补两个顺手功能：常用的订阅可以置顶固定在列表最前面；节点页的分组可以一键全部展开或全部折叠，分组多的时候不用再一个个点。

## 新功能

- **订阅置顶**：订阅页点开某个订阅卡片右边的菜单（三个点），选「置顶」，这个订阅就固定排到列表最前面，名字旁会多一个「已置顶」标记；再打开菜单选「取消置顶」即可恢复。可以同时置顶多个，多个置顶之间保持原来的先后顺序；置顶记在本机，重启应用不丢
- **节点分组全部展开／全部折叠**：节点页右上角菜单里加了「全部展开」和「全部折叠」，点一下所有分组一起展开或收起。单个分组点标题展开/收起的老用法不变，在搜索框找节点时自动展开匹配分组也不受影响

## 说明

- 这次更新的是 Android 版；按三平台同页的规矩，本页照样附上 Windows 现行正式版（1.6.5）和 Linux 现行正式版（1.0.0）的安装包
- 本版与 1.2.8 起的版本是同一把签名钥匙，可以直接覆盖升级，不用卸载

## 真机建议验一下

- 订阅页：点任一订阅卡片右边的三个点菜单，选「置顶」——该订阅应立刻排到列表最前面，名字旁出现「已置顶」标记；把应用杀掉重新打开，置顶还在。再对同一个订阅选「取消置顶」，顺序应恢复。再多置顶两个，确认它们都排在前面、彼此之间的顺序和置顶前一致
- 节点页：点右上角三个点菜单，选「全部展开」，所有分组应一起展开显示节点；选「全部折叠」，所有分组一起收起。再点单个分组的标题，展开/收起照旧能用；在搜索框输入节点名，匹配的分组仍会自动展开
