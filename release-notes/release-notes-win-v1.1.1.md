# TuxunDL Windows 1.1.1 — 全部测速与日志搜索

## 新功能

- **节点页「全部测速」**：点一下，所有分组的节点一次测完，不用再逐组点。测速时按钮会显示「测速中…」，测完延迟直接标在每个节点后面，配合「按延迟排序」挑最快的节点特别方便
- **日志页搜索**：日志多了不用翻，输入关键词只看对得上的行，查错误、查某个域名都快很多

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.1.1.msi`
- EXE 安装包：`TuxunDL-1.1.1.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 节点页点「全部测速」，等它跑完，看每个节点的延迟有没有都标上
- 日志页搜一个词（比如 error），看是不是只剩对得上的行
