# TuxunDL Android 1.6.0

本版全面优化了检查更新：全 App 共用同一份检查结果，主页、设置和更新页显示的结论从此保持一致，不再出现主页提示有新版本、设置里却查不到的情况。

## 修复

- **修复主页与设置检查结果不一致的问题**：此前主页、设置的「检查更新」、设置里的「Windows 电脑版」入口各自独立检查，检查时刻不同，结果可能互相矛盾。本版新增统一的检查中心（UpdateCheckCenter），所有入口共用同一份结果，并会保存下来，重启 App 后依然有效。
- **修复新版本可能被发布列表挤掉的问题**：读取发布列表的条数从 10 条扩大到 30 条，四个平台的版本都能完整覆盖，桌面版连续发布也不会再把其他平台的新版挤出列表。

## 改进

- **手动检查强制刷新**：在设置里点「检查更新」会直接获取服务器的最新结果，不使用缓存。
- **检查结果如实显示**：结果分为三种状态——发现新版（注明版本号）、已是最新（注明最新版本号与发布日期）、检查失败（注明原因，如网络不通、接口限流或服务器错误）。检查失败不会再被显示成「已是最新」。
- **设置入口新增状态行**：不用点进去，就能看到上次检查的结论和时间；检查进行中也有明确的进度提示。
- **更新页信息更完整**：全屏更新页会同时显示当前版本和新版的发布日期，升级前一目了然。
- **更省接口额度**：自动检查在距上次成功检查不足 6 小时时直接沿用上次结论，减少触发 GitHub 接口限流的概率；ETag 缓存与 Atom 订阅源兜底均保留。

## 说明

- 本次更新的是 Android 版；按多平台同页的惯例，本页同时附带其他平台的现行正式版安装包：Windows 1.6.10、Linux 1.0.0、Mac 1.0.0。
- 本版与 1.2.8 起的版本使用同一签名，可以直接覆盖升级，无需卸载。
