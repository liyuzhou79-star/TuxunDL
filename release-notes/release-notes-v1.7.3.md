# TuxunDL Android 1.7.3

本版只有一个主题：**内置 Tor**。不用再另外安装 Orbot 之类的应用，在 TuxunDL 里点几下，整台手机的流量就能改走 Tor 网络——经过三重中继层层加密，从与你所在地完全不同的出口出去。

## 新功能

- **「洋葱路由」模式**：首页的模式栏新增第四个选项「洋葱路由」，点开进入独立的 Tor 页面。点「连接」后，App 会先在本机启动 Tor 并连通，再通过 Tor 官方的自检确认出口确实在 Tor 网络里——只有验证通过，全机流量才会切换到 Tor 出口；验证不过就不会切换，你的流量不会在没保护的状态下被送出去。
- **全机流量经 Tor**：切换完成后，手机的流量经 VPN 隧道统一从 Tor 出口发出。Tor 进程如果意外退出，流量会立刻切回原来的出口，不会静默直连。断开同样简单：在 Tor 页面点「断开」，或在首页切回规则／全局／直连任意模式，Tor 模式随即退出。
- **多种连通方式**：内置 Snowflake、obfs4、meek 三种网桥，开箱即可尝试；「智能」模式会按顺序自动尝试、卡住自动换下一种；也支持粘贴你自己领取的网桥（WebTunnel 等），页面里有「如何获取我自己的网桥？」的说明。网桥只保存在本机，不上传、不进备份导出。
- **3D 地球线路图**：Tor 页面中央是一颗可以拖动旋转的实体地球（只有各国轮廓，没有文字）。连通后，当前线路的三个中继节点会以绿色光点标在地球上，节点之间有发光的流动线相连，出口最亮；地球下方同时给出出口位置和完整路径，一眼看清流量走了哪条路。
- **第一次使用先选地区**：首次进入 Tor 页面会先问你所在地区，并记住选择（之后可在「详细信息」里更改）。网络限制较严的地区会自动关掉「智能」、改用更稳妥的默认方式，避免白白浪费尝试。
- **日志两种看法**：「详细信息」里可以看 Tor 的原始日志，也能一键切换成「人话版」通俗解读；右上角有「复制」按钮，一键复制当前正在看的这一版日志全文。
- **内置浏览**：页面顶部的 Duck 搜索栏在连通后可直接使用，搜索结果和网址都在 App 内经 Tor 打开，不经过你的真实网络。

## 说明

- Tor 只转发 TCP 流量：语音通话、游戏等走 UDP 的流量在 Tor 模式下会被拦下，不会直连发出。普通浏览、聊天、视频等 TCP 流量不受影响。
- 使用 Tor 模式需要先导入一个订阅配置（全机隧道与普通模式共用同一条），并照常授予 VPN 权限，不需要第二次授权。
- Tor 连通速度取决于网络环境与网桥可用性：在限制较严的网络里，建议领取自己的 WebTunnel 网桥后粘贴到「自定义网桥」中使用，连通率最高。
- 本次更新的是 Android 版；按多平台同页的惯例，本页同时附带其他平台的现行正式版安装包：Windows 1.6.11、Linux 1.1.1、Mac 1.0.1。安卓电视版（TV Beta）不包含 Tor 功能。
- 本版与 1.2.8 起的版本使用同一签名，可以直接覆盖升级，无需卸载。
