# TuxunDL Windows 1.6.3 — 系统匣看今日流量，测速能自动排序

## 新功能

- **系统匣菜单显示今日流量**：右键系统匣图标，菜单里多了一行「今日流量：↓ … · ↑ …」，不用打开主界面就能看今天一共跑了多少流量。数字和首页的 24 小时流量图是同一份记录，连接期间每几秒自动刷新；当天重启程序也不会清零（记录是存盘的）
- **节点页显示上次测速时间**：工具栏下面会写「上次测速 HH:MM:SS」，单个节点测速、全部测速、选最快都算。延迟数字是什么时候测的，一眼就有数，不用猜新不新鲜
- **新设置：测速后自动按延迟排序**（默认关闭）：在设置页打开后，节点页每次测速一结束就自动按延迟从低到高排好，最快的浮到最上面，省掉手动点「按延迟排序」那一步；关着的时候行为和以前完全一样

## 说明

- 这次只更新了 Windows 版，改的是系统匣菜单、节点页和设置页，其他功能和 1.6.2 完全一样
- 按三平台同页的规矩，本页照样附上 Android 现行正式版（1.3.0）和 Linux 现行正式版（1.0.0）的安装包

## 真机建议验一下

- 连接后右键系统匣图标：菜单里应有「今日流量」一行，数字和首页 24 小时图今天的部分对得上；刷一会儿网页再打开菜单，数字应该变大
- 到节点页点任意节点测速：工具栏下方应出现「上次测速」加当前时间
- 到设置页打开「测速后自动按延迟排序」，回节点页点「全部测速」：测完列表应自动按延迟从低到高排好；把开关关掉再测一次，应保持原顺序不动
