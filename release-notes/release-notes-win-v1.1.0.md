# TuxunDL Windows 1.1.0 — 大更新：连接管理与实时流量图

## 新功能

- **连接管理页（新页面）**：左侧导航新增「连接」，能看到核心当前保持的每一条连接——目标地址、走的节点、命中规则、上下行流量；可以单独断开某一条，也可以一键全部断开，每 3 秒自动刷新
- **首页实时流量图**：连上之后，首页多了一张最近两分钟的流量曲线（下载/上传两条线），网速起伏一眼看清
- **规则页搜索**：规则成百上千条时，输入域名、类型或走向就能过滤，标题会显示筛出了多少条

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）
- 1.0.0 首发以来的功能都包含在本版：系统代理与 TUN、TUN 自动提权、订阅自动更新、节点搜索与延迟排序、开机自启、连接时长、系统匣显示当前节点

## 下载

- MSI 安装包：`TuxunDL-1.1.0.msi`
- EXE 安装包：`TuxunDL-1.1.0.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 连上后打开几个网页，进「连接」页看连接在不在、单独断开一条试试
- 首页放着看两分钟，流量曲线应该跟着你的网速起伏
- 规则页搜一个常见域名（如 google），看过滤对不对
