# TuxunDL 1.3.5 — 小修小补：每周自动备份＋「更新全部」有了完成汇总

这一版还是小修小补，补两个平时用得上的改进：备份页多了「每周自动备份」开关，开了就不用惦记着手动导出；订阅页「更新全部」跑完会给一句汇总，成功几个、失败几个、失败的是哪几个，一眼看清。

## 新功能

- **每周自动备份**：备份页新增「自动备份」一节，打开「每周自动备份」开关后，每次启动应用时若距上次自动备份已超过 7 天（或从未备过），就自动把一份备份存到应用的私有目录（backups/，文件名带日期），内容和手动导出的一份完全一样（订阅、自订规则、自订 DNS、收藏节点、外观设定）；备份页会显示上次自动备份的时间。默认关闭；自动备份的文件只留在这台设备上，要带走仍用手动导出。检查只在启动时做一次，没到期不会碰订阅服务，也不会拖慢启动
- **「更新全部」完成汇总**：订阅页点「更新全部」后，不再每个订阅各弹一条提示；全部跑完后只给一句汇总——全部成功时显示「全部更新完成：成功 X 个」，有失败时显示「更新完成：成功 X 个，失败 Y 个（失败的订阅名）」，失败的是哪几个直接点名。单个订阅手动更新的提示保持原样（成功报名字、失败带原因和编辑入口）

## 说明

- 这次更新的是 Android 版；按三平台同页的规矩，本页照样附上 Windows 现行正式版（1.6.7）和 Linux 现行正式版（1.0.0）的安装包
- 本版与 1.2.8 起的版本是同一把签名钥匙，可以直接覆盖升级，不用卸载

## 真机建议验一下

- 自动备份：进备份页打开「每周自动备份」开关（默认是关的），开关下方应显示「尚未自动备份过」；完全杀掉应用再重新打开，回到备份页应看到「上次自动备份」变成了刚才的时间；再杀掉重开，时间不应变化（没到期不会重复备）；关掉开关后再重开应用，也不应再备份
- 更新全部汇总：订阅页点「更新全部」，更新期间各卡片照旧转圈；全部结束后只应出现一句汇总提示（成功 X 个；若有订阅故意填错地址，应显示失败个数并点名那个订阅），不应再逐个弹提示；再单独更新一个订阅，提示应和以前一样（成功报名字、失败带原因）
