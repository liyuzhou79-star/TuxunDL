# TuxunDL Windows 1.5.0 — 大更新：24 小时流量图

## 新功能

- **首页新增「24 小时流量」图**：在原来的实时流量曲线下面，多了一张按小时统计的柱状图——
  - 24 根柱子就是最近 24 个小时，每根柱子是那一小时实际跑掉的流量：下半截是下载、上半截是上传，颜色和实时曲线一致
  - 卡片右上角直接给出 24 小时总的下载／上传量
  - 一眼就能看出流量都花在哪个时段，半夜有没有偷跑流量也看得见
- **数据会存下来，重启不丢**：流量按小时累计后存在程序自己的数据目录里，关掉程序、重启电脑再打开，图还是原来的图，不会清零

## 说明

- 统计的是程序运行、且处于连接状态时经过的流量；程序没开着的时段自然没有数据，那几个小时的柱子就是空的，属正常现象
- 历史只保留最近 24 小时，更早的会自动清掉，不会越攒越大
- 首页内容变多了，现在整页可以上下滚动，不用担心卡片被挤掉
- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

## 真机建议验一下

- 连接后正常上网几分钟，看首页「24 小时流量」卡当前小时的柱子有没有长起来，总量对不对得上
- 关掉程序重新打开，看图是不是还在（数据没丢）
- 首页从上往下滚一遍，看所有卡片是不是都能看到
