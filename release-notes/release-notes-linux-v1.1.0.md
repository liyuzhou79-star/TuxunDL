# TuxunDL Linux 1.1.0

本版是 Linux 的**追赶版**：Linux 与 Windows、Mac 共用同一份 desktop 桌面代码，Linux 1.0.0 之后这份代码又随 Windows 1.6.2–1.6.10 连续改进了九版。本版不新增功能，只是把版本号升到 1.1.0 重新出包，一次补齐这九版的全部改进。

## 补齐的改进（随 Windows 1.6.2–1.6.10）

- 日志按级别着色，日志搜索带高亮；订阅更新失败时卡片上直接写明失败原因。
- 系统托盘显示今日流量；托盘单击切换主窗口显示/隐藏。
- 节点页显示上次测速时间；新增「测速后自动按延迟排序」开关；节点分组可一键全部展开/折叠。
- 节点延迟分档配色与安卓统一：100ms 内绿色、100–300ms 黄色、300ms 以上与超时红色。
- 主页流量图新增 7 天视图。
- 每周自动备份（设置开关）；设置新增自动备份文件管理：列表查看、打开所在文件夹、两步确认删除。
- 连接页可按总流量排序。
- 订阅置顶；订阅列表上方汇总行（总数，以及已过期/3 天内到期的个数）。
- 启动前端口占用预检：核心端口被占时如实给出原因，不再静默失败。
- 「更新全部」订阅完成后汇总点名失败的订阅。
- Ctrl+F 聚焦当前页搜索框；设置新增「恢复默认设置」两步确认（只清偏好，订阅、置顶、收藏不动）。
- 设置新增「打开数据文件夹」。

## 保持不变的说明

- 系统代理自动切换仍只支持 GNOME 桌面（gsettings）；非 GNOME 桌面请按设置页说明手动填 127.0.0.1 与混合端口。
- TUN 仍经 pkexec 只把核心以 root 启动；开机自启仍走 XDG autostart；数据目录仍是 ~/.local/share/tuxundl。
- 吉祥物仍沿用占位图标。

## 诚实边界

本版在 CI（Ubuntu）上构建通过，deb 与 AppImage 已解包核验；但 GNOME 代理开关、TUN 提权弹窗、系统托盘行为**没有在真 Linux 桌面上实测过**，第一次在真机上用这三样时请留意，有问题欢迎反馈。
