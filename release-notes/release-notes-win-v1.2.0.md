# TuxunDL Windows 1.2.0 — 规则筛选与连接搜索

## 新功能

- **规则页类型筛选**：规则页顶部多了一排类型 chips（全部 / DOMAIN / DOMAIN-SUFFIX / IP-CIDR / GEOIP / MATCH 等，按当前配置里实际有的类型自动生成），点一下只看这一类规则。标题里的总数一直都在，筛选时显示「筛出数 / 总数」，和搜索框可以叠加使用，几千条规则里找一条不用再翻半天
- **连接页搜索框**：连接页可以按目标主机、进程、规则或节点过滤了。连接多的时候，想看某个应用走了哪条线、命中了哪条规则，输个名字就筛出来；连接行里也会显示来源进程（核心有上报时）

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.2.0.msi`
- EXE 安装包：`TuxunDL-1.2.0.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 规则页点几个类型 chips，看列表是不是只剩那一类，标题数字对不对得上
- 连接页随便打开几个网页，再搜一个域名，看是不是只剩对得上的连接
