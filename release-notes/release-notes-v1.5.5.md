# TuxunDL 1.5.5 — 分应用代理全面优化：先修功能，再收拾界面

分应用代理（设置 → 网络设置 → 访问控制）这次从头到尾审计了一遍：先把功能链路里几个不声不响的毛病修掉，再把名单页收拾清楚。修的都是查有实据的问题，查过没问题的也如实写在下面。

## 功能修了什么

- **卸载残留清不掉**：以前一个应用被你勾选过、后来卸载了，它的包名会永远留在名单里——列表里看不见它（列表只显示装着的应用），自然也删不掉，导出名单还会把它带出去。现在打开名单页时会自动把已卸载的残留清掉并保存，计数立刻就是准的
- **改动只在退出时才保存**：以前勾选只在退出页面那一刻才写盘，要是停留在这页时 App 被系统杀掉、或者任务被划掉，勾的全丢。现在每改一下立刻落盘，进程没了也不怕；退出时该做的事照旧（见下条）
- **模式和名单分家、名单页看不到模式**：以前模式藏在网络设置页，名单在单独一页，两边不照面。最坑的是模式停在「允许所有应用」时，在名单页勾什么都不生效，界面一个字都不提醒。现在名单页顶部直接能切模式（和网络设置页是同一份设置，改哪边都同步），并且明写当前模式和已选个数；模式是「允许所有」时有一行红字提醒：名单暂时不生效
- **连接中改动会静默重连**：以前连接中改了名单，退出页面时会一声不吭把连接断开重连一次。现在页面上提前写清：连接中改动「退出本页时自动重连后生效」，没连接时「下次连接时生效」，不再让你对着突然的重连纳闷

## 界面收拾了什么

- 顶部一张卡片：模式三段切换（全部／仅所选／排除所选）＋状态行（当前模式 · 已选 N 个＋生效说明），进页面先把状态看明白再勾
- 加载有反馈了：应用多的时候要逐个读名称和图标，以前这段时间是白屏，现在有转圈；搜索没结果或没有可显示的应用时，会写明「没有可显示的应用」，不再一片空白
- 原来的好东西都保留：搜索（名称和包名都能搜）、只显示第三方应用开关、全选／反选／清空、四种排序、剪贴板导入／导出，已选应用在列表里自动排前面

## 查过没问题、这次没动的（如实说明）

- 生效链路本身是通的：建立隧道时确实按模式调用了系统的按应用放行／拦截，不是只存不用；选择一直存在本机设置里，重启 App、重启手机都还在
- TuxunDL 自己不会把自己坑了：名单里本来就搜不到它，「仅所选」时系统层自动把自己带上，「排除所选」时自动把自己摘掉
- 列表加载本来就在后台线程异步跑，不卡界面；这次只是补上了加载中的可见反馈

## 已知边界（如实说明）

- 分身／双开应用（系统分身、其他安卓用户下的克隆）不在当前用户的应用列表里，这一页管不到它们
- 备份目前不包含分应用代理的选择（其它网络设置同样没进备份，是整类设置的事），这次没有动备份

## 真机建议验一下

- 设置 → 网络设置 → 访问控制应用包列表：页面顶部能直接切三种模式；切完回网络设置页看，那边的模式应该跟着变
- 模式选「仅所选」，勾几个常用应用，退出页面再进来：勾选还在；把 App 从最近任务划掉（或强行停止）再进：勾选也应该还在
- 连接中进名单页改勾选：页面上应有「退出本页时自动重连后生效」的提示；退出后连接断开重连一次，新名单生效（例如把浏览器移出「仅所选」，浏览器流量应不再走代理）
- 模式选「允许所有应用」进名单页：应有红字提示名单不生效
- 先勾一个应用，再去系统设置里把那个应用卸载，重新进名单页：已选计数应自动少一个（残留被清掉了）
- 应用装得很多时进名单页：先看到转圈，然后列表出来；搜一个不存在的名字：显示「没有可显示的应用」
- 在名单里搜 TuxunDL：应该搜不到自己，这是故意的（防止把自己拦在门外）
