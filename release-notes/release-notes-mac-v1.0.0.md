# TuxunDL Mac 1.0.0 — 首版：Mac 版来了

## 这一版有什么

- **Mac 首版**：和 Windows、Linux 版同一套桌面代码（同源开发，不仿其他客户端），六个页面齐全——首页、节点、连接、订阅、规则、日志、设置，功能与 Windows 版 1.6.10 对齐：主题色自订、订阅流量与到期提醒、首页 24 小时流量图、数据备份恢复、菜单栏模式切换等都在
- **内置 mihomo 核心**：安装包自带 mihomo v1.19.16（darwin-arm64），装完即用，不用另外下载
- **系统代理模式**：点连接就自动设置当前网络服务（一般是 Wi-Fi）的 HTTP／HTTPS／SOCKS 代理，走 `networksetup`，需要管理员账号；断开时自动关掉，只关自己开的代理，不碰你其他的代理设置
- **开机自启**：写入 ~/Library/LaunchAgents（登录时自动打开），只对当前用户生效
- **检查更新只认 Mac 发布**：只认 `mac-v` 开头的标签，与 Android、Windows、Linux 各走各的，不会串扰；检查结果分三种（有新版／已是最新／检查失败），失败如实提示，主接口被限流时自动改走发布订阅源兜底（与 Windows 1.6.1 同一套修法）
- **数据目录**：放在 ~/Library/Application Support/tuxundl，设置页能一键打开

## 先说清楚（诚实说明）

- 这是 Mac 版的第一个版本，**还没在真实 Mac 上实测过**：开发和打包都在 CI 上完成并核对了产物，但系统代理、菜单栏图标这些要跟系统打交道的功能，需要在真机上再验一遍；遇到问题欢迎到仓库提 issue
- **未签名、未公证**：首次打开时 macOS 会拦下（Gatekeeper），请在 DMG 里把 TuxunDL 拖进应用程序后，到应用程序里右键点 TuxunDL → 打开，点一次“打开”放行，之后双击就能直接用
- **只有 Apple Silicon（M 系列芯片）的包**：本版只出了 arm64 的 DMG，Intel Mac 暂时装不了；等之后有办法再补
- **TUN 模式本版暂不支持**：以管理员权限启动核心的方案还没在真 Mac 上验证过，设置页里直接写明了，点了也不会切过去；先用系统代理模式连接
- 系统代理自动设置需要管理员账号；非管理员账号改不成功时会在日志页如实说明，请在系统设置里手动把代理填成 127.0.0.1:7890（端口可在设置页改）
- 吉祥物暂时沿用窗户造型占位，Mac 版专属吉祥物之后再定
- 按多平台同页的规矩，本页同时附上 Android 现行正式版（1.5.0）、Windows 现行正式版（1.6.10）与 Linux 现行正式版（1.0.0）的安装包

## 下载

- Android 版（现行正式版）：`tuxundl-1.5.0-arm64.apk` / `tuxundl-1.5.0-legacy-armeabi-v7a.apk`，也在本页附件里
- Windows 版（现行正式版）：`TuxunDL-1.6.10.msi` / `TuxunDL-1.6.10.exe`，也在本页附件里
- Linux 版（现行正式版）：`TuxunDL-1.0.0.deb` / `TuxunDL-1.0.0.AppImage`，也在本页附件里

## 真机建议验一下

- 系统代理模式：连上后浏览器能不能上网；断开后系统代理有没有自动关掉
- 菜单栏：图标在不在，菜单能不能打开主界面、断开、退出
- 开机自启：打开开关后重启电脑，TuxunDL 有没有自动打开
- 设置页点「检查更新」：应显示「已是最新版」；断网再点，应显示「检查失败」
