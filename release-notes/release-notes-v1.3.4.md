# TuxunDL 1.3.4 — 小修小补：首页流量图能看最近 7 天＋节点页显示上次测速时间

这一版还是小修小补，补两个顺手的小改进：首页流量监控卡的逐日图多了一个「最近 7 天」的看法；节点页会显示上次测速的时间，测没测过、什么时候测的一眼就知道。

## 新功能

- **首页流量图「最近 7 天」**：逐日图原来只有「本周／上周」两种切法，现在和它们并列多一个「最近 7 天」——从今天往前推 7 天，逐日一条，顶上照样给出这段时间的合计。看最近一周用了多少流量，不用再对着日历凑周了。数据就是原来那份按天统计（本机保留 14 天），统计口径没变；哪天没有记录就不列哪天
- **节点页显示上次测速时间**：节点页搜索框下方多一行小字「上次测速 时:分:秒」。点单个节点测速、或者对整个分组测速，任何一个测完都会把这个时间刷新；时间记在本机，退出节点页再进来、杀掉应用重开都还在。从没测过速的时候这一行不显示

## 说明

- 这次更新的是 Android 版；按三平台同页的规矩，本页照样附上 Windows 现行正式版（1.6.6）和 Linux 现行正式版（1.0.0）的安装包
- 本版与 1.2.8 起的版本是同一把签名钥匙，可以直接覆盖升级，不用卸载

## 真机建议验一下

- 首页流量卡：逐日图的切换应有三个选项（本周／上周／最近 7 天）。切到「最近 7 天」，应列出今天往前 7 天内有记录的日子、每天一条横条，顶部合计等于这些天的总和；再切回本周／上周，显示应和以前一致
- 节点页：先看搜索框下方——从没测过速就没有「上次测速」这一行；点某个节点自己的测速按钮，测完后应出现「上次测速」加刚才的时间；再对某个分组做整组测速，完成后时间应刷新成新的；退出节点页再进来、或杀掉应用重开，这一行的时间应保留不变
