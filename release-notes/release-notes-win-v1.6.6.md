# TuxunDL Windows 1.6.6 — 订阅能置顶，设置页能打开数据文件夹

## 新功能

- **订阅置顶**：订阅页每张卡片多了「置顶／取消置顶」按钮，置顶的订阅固定排在列表最前面（多个置顶之间保持原来的相对顺序），名字旁标「已置顶」；选择存在设置里，重启不丢，删掉某个订阅时它的置顶记录会一起清掉。只是显示顺序排到前面，订阅本身的存储、更新和设为当前的逻辑都没变
- **设置页「打开数据文件夹」**：设置页新增「数据文件夹」一节，写明文件夹的当前位置，点按钮直接用资源管理器打开——订阅、设置、日志和核心文件都存在这里，手动备份、找日志排查问题或者卸载前清理时不用再到处找；万一没能自动打开，这一节里也写了完整路径，可以照着手动打开（Linux 版同一个按钮走 xdg-open 打开）

## 说明

- 这次只更新了 Windows 版，改的是订阅页和设置页；Linux 版仍为 1.0.0，版本号没动（置顶和打开数据文件夹是共享代码，Linux 下次发版时自然带上）
- 按三平台同页的规矩，本页照样附上 Android 现行正式版（1.3.3）和 Linux 现行正式版（1.0.0）的安装包

## 下载

- MSI 安装包：`TuxunDL-1.6.6.msi`
- EXE 安装包：`TuxunDL-1.6.6.exe`
- Android 版（现行正式版 1.3.3）：`tuxundl-1.3.3-arm64.apk` / `tuxundl-1.3.3-legacy-armeabi-v7a.apk`
- Linux 版（现行正式版 1.0.0）：`TuxunDL-1.0.0.deb` / `TuxunDL-1.0.0.AppImage`
- 以上都在本页附件里

## 真机建议验一下

- 到订阅页给某个订阅点「置顶」：它应立刻排到列表最前、名字旁出现「已置顶」；重启程序后仍在最前；再点「取消置顶」应回到原来的位置
- 到设置页「数据文件夹」点「打开数据文件夹」：应弹出资源管理器并停在页面上显示的那个路径，里面能看到 subscriptions.json、settings.json 和 profiles 文件夹
