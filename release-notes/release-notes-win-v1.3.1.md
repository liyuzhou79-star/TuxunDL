# TuxunDL Windows 1.3.1 — 首页显示订阅流量

## 新功能

- **首页新增「订阅流量」卡片**：当前正在用的订阅如果带流量信息（服务商在拉取订阅时返回的用量数据），首页会多出一张卡片，一眼看清套餐还剩多少：
  - 已用 / 总量，带百分比和一条进度条，用得越多条越满
  - 服务商给了到期时间的话，卡片上同时显示到期日期
- 服务商没返回流量信息的订阅就不显示这张卡，首页和以前一样，不占地方

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.3.1.msi`
- EXE 安装包：`TuxunDL-1.3.1.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 打开首页，看正在用的订阅有没有出现「订阅流量」卡片，已用 / 总量和订阅页卡片上对不对得上
- 换一个没有流量信息的订阅设为当前，再回首页看卡片是不是消失了
