# TuxunDL 1.0.1

1.0.0 正式版後的小修補。

## 這個版本有什麼

### 節點頁搜尋（新）
- 節點選擇頁頂部加常駐搜尋框，輸節點名片段即時篩選，不分大小寫
- 搜尋時只顯示有結果的分組，清空後全部回來

### 延遲排序（修）
- 排序選項改名「排序：延遲由低到高」：已測速的節點按延遲由低到高排，沒測過的沉底並標「未測試」（之前沒測過的反而排最前面）
- 排序偏好重開 App 後仍記得

### 順手修
- 搜尋後點測速/選節點，作用的分組不再錯位

## 下載與安裝
- 標準版（arm64 新機型）：下載 `tuxundl-1.0.1-arm64-v8a.apk`
- 老機型版（32 位舊機型）：下載 `tuxundl-1.0.1-legacy-armeabi-v7a.apk`
- 標準版從 1.0.0 升級：同一把固定鑰匙簽名，直接覆蓋安裝
- 源代碼：點下面的 Source code (zip) 下載，或看 tag `v1.0.1`
