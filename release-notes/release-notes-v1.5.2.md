# TuxunDL 1.5.2 — 优化补丁：首页流量砖不再连累整片卡片

这一版是性能优化补丁，界面和功能没有任何变化，只修了一处看不见的浪费。

## 优化内容

- 连接时，首页的流量总数大约每秒跳一次。之前这组数字是和整片卡片区一起构建的：数字每跳一次，下面所有卡片（节点、订阅、流量、代理等）都跟着重新画一遍，其实它们的内容根本没变。现在改成只有流量这一块卡片自己读数字、自己更新，其他卡片不再陪跑，首页在连接状态下更省电、也更跟手
- 流量卡片本身显示的上下行总量、点它进流量高级页、长按测速、拖拽排序和编辑模式，行为全部照旧；流量监控卡的实时图表和采样逻辑没有动

## 顺带检查过、本版没动的

- 节点页和订阅页的列表：滚动用的稳定键、分组内的排序缓存都已经在位，行里也没有滚动时反复重算的重活，不需要改
- 冷启动：每日流量和已保存连接的读取本来就在后台线程做，自动备份的启动检查也一样，主线程没有同步读大文件
- 各页面进出时的数据刷新：订阅页是事件驱动的本地查询（不是网络请求），也是数据保持新鲜的机制，节流它反而会让数据变旧，所以不动

## 真机建议验一下

- 连上节点后停在首页：流量卡片的上下行数字应照常每秒更新；其他卡片（当前节点、订阅名、模式）显示不应闪烁或跳动
- 长按卡片进编辑模式、拖动换位、点各卡片跳转，都应和 1.5.1 时一样
- 流量监控卡的实时曲线照常滚动，点开全屏图照常能看
- 断开连接后，流量数字应停住不再跳
