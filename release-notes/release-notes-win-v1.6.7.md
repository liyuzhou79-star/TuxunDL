# TuxunDL Windows 1.6.7 — 节点延迟有了颜色，端口被占会说人话

这一版是两个小改进：节点列表里的延迟数字按快慢分档着色，一眼看出哪个节点快；连接之前会先检查端口，被别的程序占了就直接讲明原因和解法，不再只报一个看不懂的连接失败。

## 新功能

- **节点延迟分档配色**：测速之后，延迟数字按档显示颜色——100ms 以内绿色、100–300ms 黄色、300ms 以上红色，超时也是红色。还没测过的节点维持原来的样子，不会误导
- **连接端口占用提示**：点连接时先查混合端口和控制端口是否已被占用（多半是其他代理程序在用，或者上次的核心没退干净）。真被占了，提示里会写清是哪个端口被占、怎么办：到设置页把混合端口改成别的数字，或者关掉占用它的程序再试

## 说明

- 这次更新的是 Windows 版；按三平台同页的规矩，本页照样附上 Android 现行正式版（1.3.4）和 Linux 现行正式版（1.0.0）的安装包
- 这两处改动都在桌面端共享代码里，Linux 版下一次发版时也会带上

## 真机建议验一下

- 节点页：对一组节点测速，看延迟数字的颜色——快的应是绿色、中等黄色、慢的和超时的红色
- 端口提示：先开着另一个代理程序（让它占用 7890 端口），再回 TuxunDL 点连接——应看到明确提示说混合端口已被占用，而不是泛泛的连接失败；按提示到设置页换一个端口，应能正常连接
