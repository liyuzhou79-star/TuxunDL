# TuxunDL 1.0.0（正式版）

> **這是 TuxunDL 的第一個正式版。** 基於 mihomo 核心的開源安卓代理工具，GPL-3.0 完全開源。從 0.1.0 走到今天，首頁、節點、規則、DNS、主題、小組件都已是自家樣子。

## 這個版本有什麼

### 設定備份還原（新）
- 設定 → 備份與還原：一鍵匯出 .json 備份（設定檔、規則、DNS、收藏、主題與偏好），換手機一鍵匯入還原
- 匯入會自動重建訂閱設定檔、跳過已存在的，結果逐項告訴你；Age 私鑰絕不匯出

### 每日流量統計（新）
- 流量監控卡新增「今日 ↑↓」與近 7 日流量列表，殺掉重開還在
- 小字說明：僅統計 App 開啟期間的流量

### 正式版打磨
- 「Meta Features」改名「核心功能」，關於頁顯示 `TuxunDL 1.0.0（正式版）`
- README 頂部標明正式版

## 之前版本累積的主要功能
- 首頁流量監控折線圖、訂閱流量卡、連接時長
- 分流規則可視化編輯器、自訂 DNS、桌面小組件、自訂主題色、卡片自訂排序
- 節點收藏置頂、檢查更新（App 內直接提示新版）
- 免責聲明、分應用代理、相簿掃碼導入

## 下載與安裝
- 標準版（arm64 新機型）：下載 `tuxundl-1.0.0-arm64-v8a.apk`
- 老機型版（32 位舊機型）：下載 `tuxundl-1.0.0-legacy-armeabi-v7a.apk`
- 標準版從 0.9.0 升級：同一把固定鑰匙簽名，直接覆蓋安裝
- 源代碼：點下面的 Source code (zip) 下載，或看 tag `v1.0.0`
