# TuxunDL Windows 1.5.1 — 首页模式快捷切换

## 新功能

- **首页大按钮下方加了一排模式按钮**：规则 / 全局 / 直连，当前用的是哪个一眼能看到（高亮显示），点一下就换，不用再去设置里找——
  - **规则**：按订阅自带的规则分流，该直连的直连、该走代理的走代理，日常默认用这个
  - **全局**：所有流量都走当前选中的节点
  - **直连**：所有流量都不走代理，临时不想用代理又懒得断开时用它

## 说明

- **切换后下次连接生效**：模式和设置里的日志级别、端口一样，是写进核心配置的；正在连接时点了切换，断开重连一次就按新模式走
- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.5.1.msi`
- EXE 安装包：`TuxunDL-1.5.1.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 在首页分别点规则 / 全局 / 直连，看高亮是不是跟着走、下面有没有提示「下次连接生效」
- 切到全局后断开重连，查一下出口 IP 是不是节点所在地；切到直连重连，出口 IP 应该是本地网络
