# TuxunDL Windows 1.2.1 — 订阅一键更新全部

## 新功能

- **订阅页「更新全部」**：订阅页右上角多了一个「更新全部」按钮，点一下就按顺序把所有订阅刷新一遍，不用再一个个点。刷新时按钮上会显示进度（如「更新中 2/5」），状态栏也会写明正在更新哪一个；某个订阅失败不会中断其余的，最后会给出结果——全部成功显示「全部更新完成」，有失败的会写清成功几个、失败几个。正在用的那个订阅更新后，当前配置会同步换新

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.2.1.msi`
- EXE 安装包：`TuxunDL-1.2.1.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 订阅页点「更新全部」，看按钮上的进度数字走不走、最后的结果提示对不对
- 故意把某个订阅链接改错再点一次，看是不是其余订阅照常更新完、结果里报了 1 个失败
