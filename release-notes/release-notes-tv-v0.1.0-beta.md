# TuxunDL 电视版 0.1.0 Beta（试水版）

这是 TuxunDL 第一次上电视。定位先说清楚：**这是一个试水版**，目标只有三件事——装得上、能从电视主页打开、遥控器能基本操作。界面直接沿用手机版，**没有做电视专属的界面改版**；先验证这条路走不走得通，再决定要不要投入做大屏界面。

电视版是独立应用（包名 `com.tuxundl.android.tv`），和手机版互不覆盖、可以同时装，数据不互通。

## 下载哪个包

| 文件 | 适合的电视 |
| --- | --- |
| `tuxundl-tv-0.1.0-beta-arm64.apk` | 大多数较新的电视和盒子（64 位芯片），先试这个 |
| `tuxundl-tv-0.1.0-beta-armeabi-v7a.apk` | 老电视、32 位芯片的电视（装不上上面那个就换这个） |

## 怎么安装

电视版不上架任何应用商店，靠手动装包：

1. 在电脑或手机上下载上面的 APK 文件；
2. 拷到 U 盘，插到电视上；
3. 用电视自带的文件管理器（或「应用安装器」之类工具）打开 U 盘里的 APK 安装；系统若提示，先允许「安装未知来源应用」；
4. 装好后回到电视主页，在应用列表里找 **TuxunDL**（带电视横幅图标），遥控器点开即可。

Google TV 和国内品牌电视（小米、TCL、海信、创维等）都能用这套装法，不依赖 Google 服务。系统版本最低要求 Android 5.0，与手机版相同；老电视装 32 位包。

第一次开启连接时，系统会弹一个 VPN 授权框，遥控器按 OK 确认即可。

## 能用的

- 电视主页能看到 TuxunDL 入口，遥控器可以直接打开；
- 主页：打开 App 后焦点自动落在大的电源按钮上，按钮有明显的焦点环，按 OK 就能开/关连接，长按菜单也能用；
- 模式切换（规则 / 全局 / 直连）、定时与夜间面板：遥控器可达；
- 主页各功能入口砖（订阅、节点、设置等）：遥控器可达，聚焦时有主题色边框；
- 订阅与节点列表：列表项聚焦有可见边框，OK 键可选中/切换；
- 添加订阅：粘贴链接、文件导入照常；电视带摄像头时也可以扫码（扫码用的是应用自带识别模型，不依赖 Google 服务）；
- 设置页大部分条目遥控器可达。

## 还不行的 / 已知边界

- **没有电视专属界面**：页面仍是手机布局，靠方向键一步步移动焦点；本版只保证上面列出的主要通路，没有逐页做完遥控审计，个别深层页面可能不好操作；
- **拖拽类操作用不了遥控器**：主页砖块拖拽排序、流量图双指缩放/滑动查看等触摸手势不在本版遥控范围；
- **「相册识图」导入在电视版已隐藏**：这项功能用的识别模型要靠 Google Play 服务下发，国内电视大多没有 Google 服务，开了也用不了，所以直接关掉；扫码和链接/文件导入不受影响；
- **电视版不自动检查更新**：手机版的更新检查只认手机版本，放在电视上会误报，已关闭。Beta 期间出了新版，下载新 APK 覆盖安装即可升级（签名相同，不用先卸载）；
- 输入订阅链接要用电视的软键盘，比较慢；也可以先在手机上准备好链接，用文件导入等方式绕过去；
- 低配电视上首次加载订阅、测速时可能稍慢，属于正常现象。
