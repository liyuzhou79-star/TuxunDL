# TuxunDL Android 1.6.3

本版把首页一张重复的卡片换成了真正有用的「出口信息」，并让测速可以自己选测速地址：测出来的延迟从此更贴近你实际访问常用网站的速度。

## 新功能

- **首页「出口信息」卡片**：原来首页右侧的「节点选择」卡片与「当前节点」卡片点进去是同一个页面，本版把它换成出口信息卡片。连接后，卡片直接显示当前出口所在的国家/地区与城市（带国旗）、出口 IP 和已连接时长，一眼就能确认流量到底是从哪里出去的。切换节点后会自动重新查询；查询失败时会如实显示「出口 IP 未知」，不会编造位置。点击卡片进入进阶统计页查看连接详情。原有首页布局不受影响：卡片的位置、顺序和显示开关都沿用原来的设置。
- **测速源可选择**：在节点选择页右上角菜单里新增「测速源」，内置三个常用地址——谷歌（gstatic）、谷歌（google.com）、Cloudflare——也可以填自己的测速地址。之后单节点测速、整组测速和「选最快」都会用你选的地址来测，「上次测速」一行也会标明当前测速源。不改设置时，默认仍是此前一直在用的谷歌 gstatic 地址，行为不变。

## 说明

- URLTest / Fallback 分组内部的自动健康检查由内核按订阅配置执行，仍使用订阅自带的测速地址，不跟随本次的测速源设置；由你手动发起的测速全部跟随。
- 本次更新的是 Android 版；按多平台同页的惯例，本页同时附带其他平台的现行正式版安装包：Windows 1.6.11、Linux 1.1.1、Mac 1.0.1。
- 本版与 1.2.8 起的版本使用同一签名，可以直接覆盖升级，无需卸载。
