# TuxunDL Windows 1.3.0 — 大更新：数据备份与恢复

## 新功能

- **设置页新增「数据备份」：导出备份 / 导入备份**。换电脑、重装系统、或者单纯想留个底，都不用再手动重录订阅了：
  - **导出备份**：点一下，用系统保存对话框选个位置，把订阅列表和全部设置（连接模式、端口、开机自启、自动连接、关闭行为、自动更新间隔等）存成一个 JSON 文件
  - **导入备份**：选之前导出的 JSON 文件，订阅和设置一次恢复回来，设置页会立刻按恢复后的设置刷新
  - 备份里只有订阅名称、链接和设置项，不含任何密钥类信息（本程序本来也没有）
  - 注意：订阅的配置文件不在备份里（链接在，配置随时能重新拉）。导入后到订阅页点一次「更新全部」重新拉取，再选一下当前订阅就齐了

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.3.0.msi`
- EXE 安装包：`TuxunDL-1.3.0.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 先点「导出备份」存一个文件，用记事本打开看看，订阅和设置是不是都在里面
- 随便改两个设置（比如端口和自动更新间隔），再「导入备份」选刚才的文件，看设置是不是变回导出时的样子、订阅列表对不对
- 导入后去订阅页点「更新全部」，确认配置能正常重新拉下来
