# TuxunDL 0.8.0：檢查更新修復 + 老機型版登場

> TuxunDL 是基於 mihomo 核心的安卓代理工具，完全開源（GPL-3.0）。這一版修好檢查更新，並從這版起每個版本都同時出標準版和老機型版。

## 這個版本有什麼

### 檢查更新修復（重要）
- 之前版本檢查更新會顯示失敗：原因是發布被標成了「預發布」，App 查的接口只認正式版。v0.7.0 已在發布端修正，這一版再把 App 端改成查清單接口＋雙保險，以後不會再整台失效
- 更新磚的下載會按你的版本挑對的包：標準版拿 arm64 包，老機型版拿 legacy 包

### 老機型版（新）
- 新增老機型適配版：包名 `com.tuxundl.android.legacy`，給 32 位（armeabi-v7a）老機型，應用名同樣是 TuxunDL，可與標準版共存安裝
- 從這一版起定為鐵律：每個新版本兩個版一起出、同版本號、同一個發布頁

### 小修補與貼圖
- 訂閱更新通知、文件選擇器、快速設定磚、Logcat 通知的舊圖示全換成 TuxunDL 的 T 字圖示與品牌色
- 關於頁加了地球圖裝飾
- 修了老機型版下桌面圖示開關會失效的隱藏問題（圖示別名寫死了標準版包名）

## 下載與安裝
- 標準版（arm64 新機型）：下載 `tuxundl-0.8.0-arm64-v8a.apk`
- 老機型版（32 位舊機型）：下載 `tuxundl-0.8.0-legacy-armeabi-v7a.apk`
- 標準版從 0.7.0 升級：同一把固定鑰匙簽名，直接覆蓋安裝
- 源代碼：點下面的 Source code (zip) 下載，或看 tag `v0.8.0`
