# TuxunDL Windows 1.3.3 — 日志级别可选

## 新功能

- **设置页新增「日志级别」**：核心写日志的详细程度现在可以自己选，四档：
  - **info**：默认档，日常使用就是它，连接、切换、报错都会记
  - **warning**：只记警告和错误，日志清净不少
  - **error**：只记错误，平时基本不产生新日志
  - **silent**：基本不记日志，想要彻底清净时用
- 排查问题时反过来也方便：留在 info 档，日志页里信息最全

## 说明

- 改完不用重启程序，下次连接时生效；正在连接的话，断开重连一次就换过来了
- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.3.3.msi`
- EXE 安装包：`TuxunDL-1.3.3.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 到设置页把日志级别切到 error，断开重连，随便用一会儿，再去日志页看核心日志是不是基本没新增
- 再切回 info，重连一次，看日志是不是又恢复记录了
