# TuxunDL Mac 1.0.1

本版为桌面版新增了首次启动引导，第一次打开就能一步步完成初始设置；数据目录也可以自由更改，订阅、设置和日志可以存到任意位置。本版与 Windows 1.6.11、Linux 1.1.1 为同一批改动（同一套桌面代码）。

## 新功能

- **首次启动引导（五步）**：欢迎 → 免责声明 → 添加订阅 → 安装与数据目录 → 主题与完成。走完一次后不再出现。
  - 免责声明需要滚动读完后才能点「同意并继续」；点「不同意，退出」会直接关闭程序。
  - 添加订阅一步可以粘贴订阅链接直接拉取并设为当前订阅，也可以整个跳过，之后在订阅页添加效果相同；拉取失败只会提示原因，不会卡住流程。
  - 第 4 步会分开写明程序的位置（.app 的位置）和数据存放的位置。
  - 主题选择与设置页使用同一套主题预设，选完立即生效。
- **数据目录可改**：在引导第 4 步和设置页的「数据文件夹」一节都可以更改数据目录。选好新文件夹后，现有数据会自动迁移过去，之后的数据都存到新目录；使用自定义目录时，还可以一键恢复默认目录。订阅、设置、日志、流量记录和备份都会跟着新目录走，不会分散在两个地方。默认数据目录仍为 `~/Library/Application Support/tuxundl`。

## 说明

- **已有用户升级后也会看到一次引导**：引导的完成标记是本版新增的，旧设置里没有这个标记，所以从 1.0.0 升级到 1.0.1 后，第一次打开也会出现一次引导。走完一遍即可，原有订阅和设置不会受到任何影响；添加订阅一步可以直接跳过，数据目录一步保持默认即可。
- **数据迁移采用复制方式**：切换成功后，旧目录里的文件仍会保留，确认新目录一切正常后可以自行删除；切换失败时数据目录保持不变，不会丢数据。正在运行的连接不受切换影响，核心会在下次启动时改用新目录。
- **尚未签名、未公证**：首次打开请在「应用程序」里右键点 TuxunDL →「打开」放行一次，之后双击即可直接使用。
- **目前仅提供 Apple Silicon 版本**，Intel Mac 暂时无法安装。
- **TUN 模式暂不支持**，请先使用系统代理模式连接。
- 本版在 CI 环境中构建；系统代理、菜单栏图标、开机自启，以及本版新增的引导界面、选目录弹窗和数据迁移，尚待在真实 Mac 上进一步验证。
- 吉祥物仍沿用占位图标。
