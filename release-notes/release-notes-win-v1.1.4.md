# TuxunDL Windows 1.1.4 — 启动时自动连接

## 新功能

- **设置里加了「启动时自动连接」开关**：打开后，每次启动 TuxunDL 时，只要已经有拉取好的订阅配置，就自动连上，不用再手动点首页的大圆按钮。配合「开机自启」一起开，就是开机登录后全自动连上
- TUN 模式下自动连接和手动连接一样，会先弹管理员权限确认并以管理员身份重启本程序，不会跳过这一步

## 说明

- 这次只更新了 Windows 版；按双平台同页的规矩，本页照样附上 Android 现行正式版的安装包（1.2.1）

## 下载

- MSI 安装包：`TuxunDL-1.1.4.msi`
- EXE 安装包：`TuxunDL-1.1.4.exe`
- Android 版（现行正式版）：`tuxundl-1.2.1-arm64.apk` / `tuxundl-1.2.1-legacy-armeabi-v7a.apk`，也在本页附件里

## 真机建议验一下

- 设置里打开「启动时自动连接」，完全退出（系统匣右键退出）再重新打开，看它是不是自己就连上了
- 还没添加订阅时打开这个开关，启动应该一切正常、只是不自动连接
